# Reverse Everything Comments

This repository hosts public comments for [Reverse Everything](https://reverseeverything.com/), a website by Ighor July about software, reverse engineering, apps, and the stories behind the tools he uses and builds.

- [Visit Reverse Everything](https://reverseeverything.com/)
- [Explore apps by Ighor July](https://reverseeverything.com/apps/)
- [Browse comment threads](https://github.com/JulyIghor/ReverseEverything/issues)

## How comments work

[Utterances](https://utteranc.es/) connects the comment sections below blog posts to GitHub Issues in this repository.

Each article has its own comment thread, matched to its URL path. Utterances creates the matching issue automatically when someone leaves the first comment. Comments posted through the website or directly on the matching GitHub issue appear in the same thread.

## Join the conversation

Open an article on the website and scroll to its Comments section. Sign in with GitHub and authorize Utterances to post, or reply directly to the article's issue here.

Keep comments relevant to the article and respectful of other readers. Comments and your GitHub identity are public. See the [privacy policy](https://reverseeverything.com/privacy/) for details.
